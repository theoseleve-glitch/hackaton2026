# Roadmap

## Phase 0 — Plateforme commune ✅ (ce dépôt, branche r3)
Core Flutter modulaire, Supabase/PostGIS/RLS, mocks complets, docs, tests.

## Phase 1a — MVP Waze Terroir
Vrai provider carto + carte interactive, POI réels (offices de tourisme),
fiches partenaires, corridor sur vraie polyline, publication beta.

## Phase 1b — MVP GPS Écoconduite
Tracking embarqué fiabilisé (background), limites de vitesse, profils
véhicule, historique des trajets et progression du score.

## Phase 2 — Dashboards
Terroir : stats fréquentation POI pour partenaires/collectivités.
EcoDrive : dashboard flotte (entreprises, collectivités, assureurs).

## Phase 3 — Monétisation
Terroir : fiches pro, emplacements sponsorisés payants, contrats OT/régions.
EcoDrive : SaaS B2B par siège, API assureurs.

## Phase 4 — Scale
Cache géo, tuiles vectorielles, ingestion POI automatisée (OSM/datatourisme),
ML léger sur les scores, internationalisation.

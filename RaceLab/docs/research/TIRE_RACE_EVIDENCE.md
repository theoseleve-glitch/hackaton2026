# Tire profile → surface bundle, from real EFRA/IFMAR off-road race evidence (D77)

What the **top pilots actually ran** at recent IFMAR World + EFRA European off-road
championships (1/8 & 1/10), mapped to the event's track surface, **date-tagged and
recency-weighted**. Researched + adversarially verified (workflow, 2026-06-29); every row
carries a real race-report / pit-report / winning-setup / tire-company source, and the
skeptic pass corrected several dates/surfaces (noted inline). This is the *strongest* grounding
tier we have — "what wins on a known surface on a known date" — and it explicitly ages out as
tech moves (newer beats older).

## ⚠ Read-this caveats
- **Control / spec tires:** modern 1/10 Worlds (and many 1/10 Euros) mandate a CONTROL tire —
  every A-main car runs the same rubber by rule, so it proves *that tire works on that surface*
  but is NOT a free-choice preference signal. Flagged `[control]` below.
- **Elite vs club:** these are World/Euro venues and pro setups; some race rubber (control tires,
  prototypes) isn't a normal club purchase. Use this to *validate/weight* the advisor, not as the
  literal everyday pick.
- **Recency:** `current` = 2024–25, `recent` = 2021–23, `older` = pre-2021 (low weight).

## Distilled: PROFILE → surface bundle (the deliverable)
Aggregated across the confirmed events, recency-weighted:

- **Dense pin (Hot Race Sahara)** → **dry, abrasive, dusty-going outdoor dirt** with decent grip.
  *(1/8 E Worlds 2025, winner+TQ+podium — current/high.)* Validates the D76 "dense pin = dry/dusty/abrasive" mapping with race proof.
- **Web / bar tread (JConcepts Ellipse, Dirt Web 2)** → **fast, smooth, groomed / rubbered-in dry dirt** (medium-high grip). *(EFRA 1/8 2024, winner's main+Q — current/high.)* Confirms D76: web/bar is a HIGH-grip groomed-dirt tool, **not** loose and **not** greasy.
- **Aggressive pin (JConcepts Falcon / Relapse)** → **fresh, loose, loamy dirt** (early-week, soft). *(EFRA 1/8 2024 — current/high.)* Same event shows the dry-dirt evolution: loamy→aggressive pin, groomed→web/bar.
- **Clay-compound SLICK (AKA)** → **smooth, very high-bite indoor clay / blue-groove**. *(1/10 Worlds 2023, control — recent/high.)* Headline insight: at max grip on smooth clay the World class runs a **slick** in clay compound. *(The D75 advisor has no "slick" pick yet — gap.)*
- **Soft mini-pin (Raw Speed Super Mini)** → **outdoor dirt with moisture/temp swings**. *(1/10 Worlds 2025, control — current.)* Control tire, so a constrained signal.
- **Dense long-wear pin (AKA Double Down)** → **slightly dusty, abrasive dirt where tire life matters**. *(1/8 Worlds 2016/2018 — older/low.)*
- **Stagger-rib / varied-pin (Schumacher Mezzo)** → **1/10 ASTROTURF** (rear + wide-staggered-rib 4WD front). *(EFRA 1/10 Euros 2023 Utrecht, control, whole field — recent/high.)* Race-proves the D76 astro mapping (Mezzo for astro pile, stagger-rib front) — note EFRA 1/10 off-road Euros run on **astro**, not dirt.
- **Soft dirt control tyre (HUDY 303 Soft)** → **1/10 indoor hard-packed groomed dirt**. *(EFRA 1/10 Euros 2025 Trenčín, control — current.)* Another spec-tyre datapoint for indoor 1/10 dirt.

## What this changes for the advisor (D75/D76)
1. **Validates** the manufacturer-guide research (D76): dense pin = dry/dusty/abrasive (Sahara), web/bar = high-grip groomed dirt (Ellipse/Dirt-Web), loamy = aggressive pin (Falcon/Relapse).
2. **New surface state to model — "high-bite smooth clay" → clay-compound SLICK.** The current advisor keys clay → refuse (ungrounded) and has no slick option; race evidence grounds a real high-grip-clay pick. Candidate D75 addition (1/10 + 1/8 IC).
3. **Brand realism:** 1/10 Worlds/Euros are heavily **control-tire** (Raw Speed, AKA, HUDY) — for 1/10 the "what to buy" is often the spec tire; the advisor should note when a class/venue is spec-tire-controlled rather than free choice.
4. **Within-event evolution is real** (loamy→groomed in one weekend) — supports a future "track is rubbering in / drying out → step profile" hint.

## Method / sources
Workflow `efra-ifmar-tire-race-evidence` (5 clusters: IFMAR 1/8 IC, 1/8 E, 1/10 EP; EFRA 1/8, 1/10).
Primary sources: redrc.net / events.redrc.net (chassis-focus + winning-car), liverc.com, circusrc.com,
blog.jconcepts.net (race reports), associatedelectrics.com, ifmar.org stage reports, efra.ws event pages.
Every confirmed row's URL + quote is in the workflow output; rejected/over-stated claims (e.g. "Matrix
Red Giant" = a post-event launch, not the raced tire; 2016 venue surface ungrounded) were cut.

## Cars — Off-road (by brand)

> Off-road competitive RC is dominated by 1/8 nitro/e-buggy + truggy and 1/10 2WD/4WD buggy / short course / stadium truck. Most modern kits are "convertible" platforms (one chassis builds nitro OR electric, or buggy parts shared with truggy). Naming conventions: TLR uses 8IGHT (1/8) + 22-series (1/10); Kyosho uses Inferno MP-series (nitro 1/8) + Lazer ZX (1/10 4WD) + RB (1/10 2WD); Tekno uses NB/EB (buggy nitro/electric) + NT/ET (truggy) + SCT/MT for 1/10 SC/monster; HB Racing D=nitro/E=electric, number=scale tier (D8/E8 1/8, D4 4WD, D2 2WD); XRAY XB=buggy/XT=truggy with C(carpet)/D(dirt) surface variants; Yokomo YZ. Surface-specific kit editions (Dirt vs Carpet/Astro) are now standard at 1/10 and increasingly 1/8. Dirt-OVAL is a separate niche (Custom Works, RJ Speed, 1RC) using direct-drive late-model / sprint-car chassis, not mainstream off-road. 1/5 large-scale racing centers on Losi 5IVE-B/T and HPI Baja. Team Durango and Hong Nor are largely legacy/dormant. Reference month: June 2026.

## Tires (by brand)

> COMPOUND-NAMING CONVENTIONS DIFFER BY DOMAIN. (1) Off-road (clay/dirt/loam): named by softness words — Super Soft / Soft / Medium / Medium-Soft / Hard, plus a separate Clay / Clay-Soft / Clay-Hard family for damp prepped surfaces, plus indoor-clay sub-grades. Some brands add 'Long Wear' (LW) variants (AKA, Raw Speed) that trade ~50% more tread life for grip. JConcepts uses a COLOR system: Green (super soft, cold <75F) > Aqua/Aqua-2 (dry-groove clay) > Pink (soft carpet/turf) > Gold (clay, warm/prepped) > Silver (indoor clay, softer than gold) > Black (medium/outdoor). Schumacher off-road uses Silver(softest)>Yellow(soft)>Blue(hard). Panther: Super Soft/Soft/Medium-Soft/Medium/Clay(Pink). (2) On-road RUBBER (touring/F1) uses a DUROMETER/temperature number system: 24R/28R/32R/36R/40R where the number ~= shore hardness and maps to track-temp window (lower number = softer = colder/carpet; higher = harder = hot asphalt). Solaris/Volante append a letter (J, CP, X) for construction/surface (e.g. 28J, 32J, 36J; V5 28-CP = carpet). Sweep has R-series + D-Spec (control-tire spec); many bodies (IFMAR/EFRA/region) mandate a single CONTROL tire (Volante, Sorex, Sweep widely used as spec). (3) On-road FOAM (1/12 pan, 1/10 GT12/LMP, 1/8 GT) is rated by SHORE hardness (e.g. 30/32/35/37/40/42/45 shore) and foam TYPE letters — Contact uses A/Q/J/T foam grades (J = fast/high-grip carpet); dual-compound fronts written like 37/45. INSERT/MOUSSE: off-road tires ship with foam inserts (open-cell for soft/bumpy outdoor grab; closed-cell/dual-stage for high-grip to resist traction-rolling). Insert specialists: Pro-Line (dual-stage closed-cell), Crawler Innovations, Team Ottsix, Pit Bull; SRT/Slavens 'Nitro Mousse' is an elastomer mousse insert. Most race tires (AKA, Pro-Line, HotRace, Matrix, Raw Speed) sell 'w/inserts' bundles.

## Oils & fluids — shock / diff / grease / glue (by brand)

> VISCOSITY SYSTEMS — the load-bearing fact for setup sheets: (1) cSt (centistokes, = cps/centipoise for silicone since SG~0.97) is the absolute kinematic-viscosity unit; European/Japanese brands (Mugen, Kyosho, Xray, HB, HUDY, Yokomo, AKA's oil line) label oils ONLY in cSt. (2) 'wt' (weight) is a US convention with NO industry standard — US brands (Associated/Reedy, Losi/TLR) dual-label wt + cSt. (3) Rough conversion is brand-specific, NOT universal: AE/Reedy uses ~ wt x 12.5 (30wt = 350 cSt, 40wt = 500 cSt — confirmed on AE part 5422); Losi/TLR uses ~ wt x 10-12 (30wt = 350cSt per published TLR chart). Same labeled wt differs by brand (Losi 30wt ~ AE 27.5wt). For shocks the useful band is ~100-1000 cSt; diff oils run 1,000 cSt (loose) to 500,000+ cSt (locked). NEVER cross-convert between brands by formula — use each brand's own cSt value. Tire glue (CA/cyanoacrylate) has its own viscosity scale: thin/medium/thick (flow speed, unrelated to oil cSt). Best practice: keep all shock+diff oils within ONE brand family to avoid cross-brand cSt drift.

## Engines, glow plugs & nitro fuel (by brand)

> Displacement convention is cubic-inch nomenclature derived from cc: .12 = 2.1cc (1/10 & 1/8 on-road), .21 = 3.49cc (the universal 1/8 buggy/truggy/on-road class limit), .28 = 4.6cc (larger off-road, 1/8 truggy, some monster/large-scale). Engines are sold as Off-Road (low-rev torque, conventional round cooling head) vs On-Road (high-rev, finned low-profile head). Glow plug spec is two-axis: PLUG TYPE (Turbo = conical seat/no washer, used by most modern 1/8 comp engines like O.S./Reds/Nova; Standard = flat seat with copper washer, e.g. McCoy MC59) and HEAT RANGE (cold plug for high-nitro/high-load off-road, hot plug for low-nitro/on-road/cooler running). Brands number their heat ranges differently — O.S. uses P3/P4 (turbo) for cars; Nova uses No.4 (off-road, colder) vs No.7 (on-road, hotter); McCoy uses MC8/MC9/MC59 standard plugs. FUEL nitro % is class-driven: 1/8 nitro buggy/truggy commonly run 25%-30% (EFRA/ROAR comp blends), 1/8 & 1/10 on-road 16%-25%, sportsman/bashing 20%, break-in/RTR 10%-16%. Oil content (synthetic + castor blend, typically 8-11%) matters as much as nitro for lubrication. EU racing tends toward 16-25% (lower-nitro tradition, e.g. Nitrolux); US comp runs higher 30%+. VP Racing and PowerMaster are the same company/family (VP acquired PowerMaster). Sidewinder, Maxima, Byron Gen2, Klotz are other comp blends.

## Power electronics — motors / ESCs / servos / gyros (by brand)

> STOCK-CLASS MOTOR-TURN CONVENTION (the key spec a setup sheet records): brushless sensored motors are rated by stator winding TURNS — higher turn = LOWER power / less RPM. Common spec/blinky classes: 25.5T (entry 1/12 & beginner), 21.5T (GT, F1, entry touring/off-road), 17.5T (the dominant world stock class — 1/10 touring 'Stock'/'Blinky' & 2WD/4WD off-road), 13.5T (Super Stock / 'boosted' allowed in many regions, 1/10 carpet), 10.5T (Pro Stock / Modified-adjacent). Below ~10.5T = MODIFIED class (turns drop to ~3.5T–8.5T, unrestricted timing/boost). Pan-car 1/12 often runs 13.5T/21.5T. 'Blinky' = ESC boost/timing OFF (zero-timing, ESC LED blinks); 'Boost/Turbo' = ESC adds dynamic timing in 13.5T+ classes. Off-road 1/8 e-buggy/e-truggy uses 4-pole large-can sensorless motors rated in KV, not turns (e.g. 2000KV–2200KV). GYROS for drift/touring are 1-axis (yaw) steering-assist 'silver can' style; not used in off-road/buggy (which use none). Servo competition spec = low-profile (LP) digital/brushless, rated torque (kg-cm) + speed (sec/60deg) at 6.0/7.4/8.4V.

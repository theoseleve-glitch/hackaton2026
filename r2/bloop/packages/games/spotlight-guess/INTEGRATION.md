# @bloop/game-spotlight-guess — integration

SPOTLIGHT_GUESS template, 'secret target + converging guesses' (wave-2 design
§2.10/§2.11/§3.3) — one rotating spotlight holds a per-round VALUE SECRET; the
room converges on it through a hidden guess buffer with an atomic reveal:

| gameId | Mode | Phases (phaseKey) | Durations |
|---|---|---|---|
| `jeu-de-la-note` (La Note / On a Scale) | `scale` | `target:r{n}` → `talk:r{n}` → `guess:r{n}` → `reveal:r{n}` → `over` | 8s / 45s / 20s / 8s / untimed |
| `devine-la-question` (Devine la Question / Guess the Question) | `reverse-question` | `answer:r{n}` → `guess:r{n}:h{0..2}` → `reveal:r{n}` → `scoreboard:r{n}` (every 2 rounds + before over) → `over` | 20s / 20s per tier / 8s / 6s / untimed |

Both games: 3–16 players. The scale `target` number and the reverse
`realIndex` (which candidate is the real question) are VALUE SECRETS until the
atomic reveal; unrevealed hints open one tier at a time. Every snippet below
is verified by `test/integration-audit.test.ts` in this package, which replays
the §2 adapter and the §3 fixtures against the real authored packs — keep them
in sync.

Dependency note: `apps/server/package.json` and `apps/mobile/package.json`
already declare `"@bloop/game-spotlight-guess": "workspace:*"` — no
package.json edit is needed.

## 2. Server pack consts — `scripts/build-packs.mjs` adapter

Append this block to `scripts/build-packs.mjs`, then run
`node scripts/build-packs.mjs` from the bloop root. It emits
`apps/server/src/content/spotlight-guess-packs.ts` with the export names
**`JEU_DE_LA_NOTE_PACK`** and **`DEVINE_LA_QUESTION_PACK`**
(both typed `ContentPack<SpotlightGuessContent>`).

```js
// ---------------------------------------------------------------------------
// spotlight-guess: jeu-de-la-note (scale) + devine-la-question
// (reverse-question) -> apps/server/src/content/spotlight-guess-packs.ts
// ---------------------------------------------------------------------------
const note = load('jeu-de-la-note');
// Strip authoring-only fields (tags, intensity); classic intensity only. The
// authored pack mixes scale10 and wheel100 items — the per-item kind rides
// into the runtime item and rules the guess domain per round.
const noteItems = note.items
  .filter((i) => (i.intensity ?? 'classic') === 'classic')
  .map((i) => ({
    id: i.id,
    kind: i.kind === 'wheel100' ? 'wheel100' : 'scale10',
    prompt: i.prompt,
    low: i.low,
    high: i.high,
  }));

const dlq = load('devine-la-question');
// Strip authoring-only fields (tags, spicy); spicy 0 only.
const dlqItems = dlq.items
  .filter((i) => (i.spicy ?? 0) === 0)
  .map((i) => ({
    id: i.id,
    question: i.question,
    answers: i.answers,
    decoys: i.decoys,
    hints: i.hints,
  }));

const sgOut = join(root, 'apps', 'server', 'src', 'content', 'spotlight-guess-packs.ts');
writeFileSync(sgOut, `import type { ContentPack } from '@bloop/engine';
import type { SpotlightGuessContent } from '@bloop/game-spotlight-guess';

/**
 * GENERATED by scripts/build-packs.mjs from content/packs/<gameId>.json —
 * do not edit by hand. The scale target is drawn at init from the seeded RNG
 * (never in the pack); question / decoys / hints are VALUE SECRETS until
 * their reveal tier (they never enter pre-reveal guesser views). Same R2
 * seam as tracer-pack.
 */
export const JEU_DE_LA_NOTE_PACK: ContentPack<SpotlightGuessContent> = {
  id: '${note.gameId}-core',
  version: ${note.version ?? 1},
  data: { mode: 'scale', items: ${JSON.stringify(noteItems, null, 2)} },
};

export const DEVINE_LA_QUESTION_PACK: ContentPack<SpotlightGuessContent> = {
  id: '${dlq.gameId}-core',
  version: ${dlq.version ?? 1},
  data: { mode: 'reverse-question', items: ${JSON.stringify(dlqItems, null, 2)} },
};
`);
console.log(`spotlight-guess-packs.ts regenerated — jeu-de-la-note: ${noteItems.length} items, devine-la-question: ${dlqItems.length} items`);
```

## 3. Audit fixtures — `apps/server/test-node/redaction-audit.test.ts`

Add the event helpers next to `vote` / `ballot` / `igGuess`:

```ts
const sgGuess = (playerId: string, value: number, at: number): GameEvent<unknown> =>
  ({ type: 'action', playerId, action: { kind: 'guess', value }, at });

const sgAnswer = (playerId: string, answerIndex: number, at: number): GameEvent<unknown> =>
  ({ type: 'action', playerId, action: { kind: 'answer', answerIndex }, at });

const sgDeadlines = (n: number): GameEvent<unknown>[] =>
  Array.from({ length: n }, (_, i) => ({ type: 'deadline' as const, at: 1_000 + i }));
```

Add the entries to the `AUDITS` map. These exact fixtures (same seeds, events
and secrets) are pinned green against the real packs by
`packages/games/spotlight-guess/test/integration-audit.test.ts`:

```ts
  ['jeu-de-la-note', {
    players: ['p1', 'p2', 'p3', 'p4'],
    // 'audit-seed' lands a target of 10 ("scale10" makes 0/1/10 substring-uncheckable)
    // at every reachable fixture round; this seed lands target 9 on a digit-9-free
    // round-2 item, so the stringified secret IS auditable. Round 2 keeps the
    // remaining deadline walk at 22 steps (≤ 25): 10 deadlines cross rounds 0-1
    // and the r2 target/talk beats, then two guesses buffer mid-guess (p4 still
    // expected — phase NOT advanced). Round-2 spotlight under this seed: p2.
    seed: 'audit-seed-note',
    events: [...sgDeadlines(10), sgGuess('p1', 3, 11_000), sgGuess('p3', 5, 12_000)],
    eventsAlt: [...sgDeadlines(10), sgGuess('p1', 4, 11_000), sgGuess('p3', 6, 12_000)],
    actors: ['p1', 'p3'],
    // the current round's secret target is a VALUE secret owned by the spotlight
    // (guess values above are chosen so no digit collides with it)
    secrets: (state) => {
      const s = state as { round: number; spotIndex: number; turnOrder: string[]; targets: number[] };
      const t = s.targets[s.round];
      if (t === undefined) return [];
      return [{ value: String(t), owner: s.turnOrder[s.spotIndex] }];
    },
  }],
  ['devine-la-question', {
    players: ['p1', 'p2', 'p3', 'p4'],
    seed: 'audit-seed',
    // mid-guess r0 h0: the spotlight (turnOrder[0] = p1 under this seed) answered,
    // two guessers locked, p4 still expected — phase NOT advanced. Both scripts
    // share the spotlight's answer; only the hidden candidate locks differ.
    events: [sgAnswer('p1', 0, 1_000), sgGuess('p2', 1, 2_000), sgGuess('p3', 2, 3_000)],
    eventsAlt: [sgAnswer('p1', 0, 1_000), sgGuess('p2', 4, 2_000), sgGuess('p3', 0, 3_000)],
    actors: ['p2', 'p3'],
    // VALUE secrets at this state: the current round's still-hidden hints and every
    // FUTURE round's real question text (realIndex itself is structural — covered
    // by the invariance check; candidate indexes are single digits, uncheckable)
    secrets: (state) => {
      const s = state as {
        round: number;
        hintTier: number;
        reverseRounds: Array<{
          realIndex: number;
          candidates: Array<{ fr: string; en: string }>;
          hints: Array<{ fr: string; en: string }>;
        }>;
      };
      const out: Array<{ value: string }> = [];
      const cur = s.reverseRounds[s.round];
      for (const h of (cur?.hints ?? []).slice(s.hintTier)) out.push({ value: h.fr }, { value: h.en });
      for (let r = s.round + 1; r < s.reverseRounds.length; r++) {
        const rr = s.reverseRounds[r]!;
        const q = rr.candidates[rr.realIndex];
        if (q !== undefined) out.push({ value: q.fr }, { value: q.en });
      }
      return out;
    },
  }],
```

Deadline-walk budget: from the fixture state, `jeu-de-la-note` reaches `over`
in 22 deadline steps (guess+reveal of r2, then 5 × 4 phases) and
`devine-la-question` in 17 (hint tiers + voided rounds + 3 scoreboards) —
both ≤ 25.

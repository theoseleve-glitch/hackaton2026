# @bloop/game-rule-hunt — integration

RULE_HUNT template (wave-2 design §2 *Trouvez la Règle* / by-game spec), one game:

| gameId | Phases (phaseKey) | Durations |
|---|---|---|
| `trouvez-la-regle` (Find the Rule) | `briefing:r{n}` → `live:r{n}:s{seg}` ⇄ (`tribunal:r{n}:i{k}` \| `guess:r{n}:i{k}`) → `reveal:r{n}` → `over` | 20s / banked 180s / 25s / 20s / 12s / untimed |

4–16 players, 3 rounds. 1–2 PUBLIC detectives (auto: 1 for 4–7 players, 2 for
8–16) hunt the secret rule the followers obey. The live clock PAUSES on
interrupts (accusation → tribunal, detective guess → grid) and resumes with the
banked remainder — pure event-`at` arithmetic. The rule text is followers-only
until reveal; `trueCandidateIndex` and per-voter tribunal ballots never
serialize. Every snippet below is verified by
`test/integration-audit.test.ts` in this package, which replays the §2 adapter
and the §3 fixture against the real authored pack — keep them in sync.

Dependency note: `apps/server/package.json` and `apps/mobile/package.json`
already declare `"@bloop/game-rule-hunt": "workspace:*"` — no package.json
edit is needed.

## 2. Server pack consts — `scripts/build-packs.mjs` adapter

Append this block to `scripts/build-packs.mjs`, then run
`node scripts/build-packs.mjs` from the bloop root. It emits
`apps/server/src/content/rule-hunt-packs.ts` with the export name
**`TROUVEZ_LA_REGLE_PACK`** (typed `ContentPack<RuleHuntContent>`).

```js
// ---------------------------------------------------------------------------
// rule-hunt: trouvez-la-regle -> apps/server/src/content/rule-hunt-packs.ts
// ---------------------------------------------------------------------------
const tlr = load('trouvez-la-regle');
// Core pack = spicy 0 only (launch is all-ages); authoring-only fields are
// stripped. decoys stay full 7-entry sets — the runtime grid is the seeded
// shuffle of [rule, ...decoys] and caps at candidateCount-1 decoys itself.
const tlrItems = tlr.items
  .filter((i) => (i.spicy ?? 0) === 0)
  .map((i) => ({
    id: i.id,
    category: i.category === 'verbal' ? 'verbal' : i.category === 'social' ? 'social' : 'gesture',
    difficulty: i.difficulty === 'medium' ? 'medium' : i.difficulty === 'hard' ? 'hard' : 'easy',
    rule: i.rule,
    decoys: i.decoys,
  }));

const tlrOut = join(root, 'apps', 'server', 'src', 'content', 'rule-hunt-packs.ts');
writeFileSync(tlrOut, `import type { ContentPack } from '@bloop/engine';
import type { RuleHuntContent } from '@bloop/game-rule-hunt';

/**
 * GENERATED by scripts/build-packs.mjs from content/packs/<gameId>.json —
 * do not edit by hand. The rule text is the followers' VALUE SECRET until
 * reveal (never in detective/spectator views pre-reveal); decoys surface only
 * inside the seed-shuffled guess grid. Same R2 seam as tracer-pack.
 */
export const TROUVEZ_LA_REGLE_PACK: ContentPack<RuleHuntContent> = {
  id: '${tlr.gameId}-core',
  version: ${tlr.version ?? 1},
  data: { items: ${JSON.stringify(tlrItems, null, 2)} },
};
`);
console.log(`rule-hunt-packs.ts regenerated — trouvez-la-regle: ${tlrItems.length} items`);
```

## 3. Audit fixtures — `apps/server/test-node/redaction-audit.test.ts`

Add the event helpers next to `vote` / `ballot`:

```ts
const rhAck = (playerId: string, at: number): GameEvent<unknown> =>
  ({ type: 'action', playerId, action: { kind: 'ackRule' }, at });

const rhAccuse = (playerId: string, target: string, at: number): GameEvent<unknown> =>
  ({ type: 'action', playerId, action: { kind: 'accuse', target }, at });

const rhVote = (playerId: string, guilty: boolean, at: number): GameEvent<unknown> =>
  ({ type: 'action', playerId, action: { kind: 'tribunalVote', guilty }, at });
```

Add the entry to the `AUDITS` map. This exact fixture (same seed, events and
secrets) is pinned green against the real pack by
`packages/games/rule-hunt/test/integration-audit.test.ts`:

```ts
  ['trouvez-la-regle', {
    players: ['p1', 'p2', 'p3', 'p4', 'p5'],
    seed: 'audit-1',
    // Seed 'audit-1' makes p1 the sole round-0 detective against the REAL pack
    // (the item shuffle consumes the rng before the player shuffle, so the
    // detective seat is pack-sensitive — 'audit-1' is pinned to keep p1 the
    // detective). Followers ack -> live; p2 accuses p3 -> tribunal (voters
    // p2/p4/p5); p4+p5 cast HIDDEN ballots, p2 still expected — phase NOT
    // advanced (phaseKey 'tribunal:r0:i1' both scripts).
    events: [
      rhAck('p2', 1_000), rhAck('p3', 1_100), rhAck('p4', 1_200), rhAck('p5', 1_300),
      rhAccuse('p2', 'p3', 5_000),
      rhVote('p4', true, 6_000), rhVote('p5', false, 7_000),
    ],
    eventsAlt: [
      rhAck('p2', 1_000), rhAck('p3', 1_100), rhAck('p4', 1_200), rhAck('p5', 1_300),
      rhAccuse('p2', 'p3', 5_000),
      rhVote('p4', false, 6_000), rhVote('p5', true, 7_000),
    ],
    actors: ['p4', 'p5'],
    // The CURRENT rule legitimately appears in EVERY follower's view (myRule),
    // so it cannot be a single-owner value secret here; the module's own
    // redaction suite asserts field-level that detectives/spectators never see
    // it pre-reveal. Value-auditable: the current item's decoys (hidden from
    // everyone until the guess grid opens) + the future rounds' rules.
    secrets: (state) => {
      const s = state as {
        round: number;
        items: Array<{ rule: { fr: string; en: string }; decoys: Array<{ fr: string; en: string }> }>;
      };
      const current = s.items[s.round];
      const future = s.items.slice(s.round + 1, s.round + 3);
      return [
        ...(current?.decoys ?? []).flatMap((d) => [{ value: d.fr }, { value: d.en }]),
        ...future.flatMap((i) => [{ value: i.rule.fr }, { value: i.rule.en }]),
      ];
    },
  }],
```

Deadline-walk note: the heat-check fills each round's `live` with forced
`spotlight` micro-beats, so a monotonic-clock walk reaches `over` in ~50
deadline steps (each `heatMs` slice stages one spotlight). The walk MUST
advance a real clock by each phase's armed `phaseDurationMs` — a fixed-tiny
`at` stalls inside the banked `live`/`spotlight` clock. The package
`integration-audit.test.ts` only asserts the walk reaches an untimed phase.

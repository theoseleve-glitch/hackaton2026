# @bloop/game-last-standing — integration

Wires `jeu-du-theme` (LAST_STANDING template, wave-2 design 2.14) into the
server registry, the content build, the redaction audit and the mobile app.
Every block below is copy-pasteable as-is. The package itself is already
workspace-linked (`@bloop/game-last-standing` is in `apps/server/package.json`
and resolvable from `apps/mobile`) — no dependency edits needed.

Order of operations: §2 (generate the pack) → §1 (registry) → §3 (audit
fixture, same commit as §1 — the audit coverage test fails a registry entry
without a fixture) → §4–§6 (mobile).

## 2) `scripts/build-packs.mjs` — pack adapter

Emits `apps/server/src/content/last-standing-pack.ts` with one export:
**`JEU_DU_THEME_PACK`** (`ContentPack<LastStandingContent>`, id
`jeu-du-theme-core`). Append to the script:

```js
// ---------------------------------------------------------------------------
// jeu-du-theme (LAST_STANDING) -> apps/server/src/content/last-standing-pack.ts
// ---------------------------------------------------------------------------
const jdt = load('jeu-du-theme');
// Authoring-only fields are STRIPPED: exampleWords would PRIME ANSWERS (design
// risk #9 — it must never reach a client), tags are curation-only. The
// per-locale letter lists merge into ONE shared list (fr∩en when >= 3 letters,
// else the fr list): the room shouts a single letter, so it must be identical
// on every phone regardless of device locale, and an intersection letter is
// pre-validated feasible in BOTH languages. Core pack = spicy 0 only.
const jdtItems = jdt.items
  .filter((i) => (i.spicy ?? 0) === 0)
  .map((i) => {
    const shared = i.letters.fr.filter((l) => i.letters.en.includes(l));
    return {
      id: i.id,
      theme: i.theme,
      letters: shared.length >= 3 ? shared : i.letters.fr,
      difficulty: i.difficulty === 2 ? 2 : i.difficulty === 3 ? 3 : 1,
    };
  });

const jdtOut = join(root, 'apps', 'server', 'src', 'content', 'last-standing-pack.ts');
writeFileSync(jdtOut, `import type { ContentPack } from '@bloop/engine';
import type { LastStandingContent } from '@bloop/game-last-standing';

/**
 * GENERATED by scripts/build-packs.mjs from content/packs/jeu-du-theme.json —
 * do not edit by hand. exampleWords/tags are STRIPPED at build (exampleWords
 * would prime answers). Undrawn themes are the game's only content secret;
 * the drawn theme + letter are public (shouted in the room anyway). Same R2
 * seam as tracer-pack.
 */
export const JEU_DU_THEME_PACK: ContentPack<LastStandingContent> = {
  id: '${jdt.gameId}-core',
  version: ${jdt.version ?? 1},
  data: { items: ${JSON.stringify(jdtItems, null, 2)} },
};
`);
console.log(`last-standing-pack.ts regenerated — jeu-du-theme: ${jdtItems.length} items (spicy 0 only)`);
```

A TS mirror of this exact adapter runs against the real authored pack in
`packages/games/last-standing/test/integration-audit.test.ts` — keep them in
sync if the mapping ever changes.

## 3) `apps/server/test-node/redaction-audit.test.ts` — AUDITS fixture

Event helpers (alongside the existing `vote` / `ballot` / `igGuess` helpers):

```ts
const lsDeadline = (at: number): GameEvent<unknown> => ({ type: 'deadline', at });

const lsWord = (playerId: string, at: number): GameEvent<unknown> =>
  ({ type: 'action', playerId, action: { kind: 'wordSaid' }, at });

const lsJudge = (playerId: string, vote: 'valid' | 'reject', at: number): GameEvent<unknown> =>
  ({ type: 'action', playerId, action: { kind: 'judge', vote }, at });
```

Fixture entry (inside the `AUDITS` map literal):

```ts
  ['jeu-du-theme', {
    players: ['p1', 'p2', 'p3'],
    seed: 'audit-seed',
    // Under seed 'audit-seed' the seeded rotation of [p1,p2,p3] is [p3,p1,p2]:
    // p3 opens the first say turn; p1 and p2 are the jury. Fixture state =
    // mid-judge turn 1 with ONE ballot in flight (p1), p2 still expected —
    // phase NOT advanced (fold fails loud if any event is rejected).
    events: [lsDeadline(500), lsWord('p3', 1_000), lsJudge('p1', 'valid', 2_000)],
    eventsAlt: [lsDeadline(500), lsWord('p3', 1_000), lsJudge('p1', 'reject', 2_000)],
    actors: ['p1'],
    // Undrawn theme texts are the game's only VALUE secrets. Individual votes
    // are structural ('valid'/'reject' strings legitimately appear in the
    // owner echo) — the non-actor invariance check covers them. Letters are
    // single chars (substring auditing cannot apply).
    secrets: (state) => {
      const s = state as { deck: Array<{ theme: { fr: string; en: string } }>; themeCursor: number };
      return s.deck.slice(s.themeCursor).flatMap((i) => [{ value: i.theme.fr }, { value: i.theme.en }]);
    },
  }],
```

Walk budget: from this fixture state a deadline-only walk reaches `over` in 19
steps (≤ 25): judge resolves valid (1 cast, 0 reject), then every later say
turn times out — 3 rounds of 3 players converge fast. The same fixture +
machinery is mirrored green in
`packages/games/last-standing/test/integration-audit.test.ts`.

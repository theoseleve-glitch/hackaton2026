# @bloop/game-truth-dare — integration snippets

TRUTH_DARE@2 template serving **truth-or-dare-2** (fun deck mainline; the lover
sibling `TRUTH_OR_DARE_LOVER_CONFIG` is exported, config-only, 18+-gated — do
NOT register it until the spicy flag/legal sign-off) and **truth-or-drink**
(truth-only, escape = drink/forfeit-draw).

Every block below is copy-pasteable. The package's own
`test/integration-audit.test.ts` runs the §2 adapter + §3 fixtures against the
real authored packs and the same audit machinery — if it is green, these
snippets pass the server audit as-is. Keep them in sync.

---

## 2. `scripts/build-packs.mjs` — pack adapter

Appends a generated `apps/server/src/content/truth-dare-packs.ts`. Unlike the
spicy-filtered core packs, BOTH truth-dare packs ship every entry: tier/deck
gating is a **runtime config gate** at `init` (`allowedIntensities` + `deck`),
per the ToD design §6 ("a pack may contain spicy; whether they're ever drawn
is a runtime gate"). The fun config never draws lover/spicy rows; the drink
config never draws the soft safe-sibling rows.

```js
// ---------------------------------------------------------------------------
// truth-dare: truth-or-dare-2 (fun+lover decks) + truth-or-drink (questions +
// forfeit pool) -> apps/server/src/content/truth-dare-packs.ts
// Authoring metadata (spicy, minAge, tags, generatedAt) is stripped; the
// fun/lover deck is derived from the id prefix. Tier + deck gating happens at
// init via each game config — NOT here (ToD design §6 runtime gate).
// ---------------------------------------------------------------------------
const asChoice = (c) => (c === 'dare' ? 'dare' : 'truth');
const asTier = (t) => (t === 'spicy' ? 'spicy' : t === 'party' ? 'party' : 'soft');

const tod2 = load('truth-or-dare-2');
const tod2Items = tod2.items.map((i) => ({
  id: i.id,
  choice: asChoice(i.choice),
  intensity: asTier(i.intensity),
  text: i.text,
  deck: i.id.startsWith('lov-') ? 'lover' : 'fun',
  ...(i.props === true ? { props: true } : {}),
}));

const totd = load('truth-or-drink');
// truth rows = the questions; dare rows = the FORFEIT POOL (drawn on escape).
const totdItems = totd.items.map((i) => ({
  id: i.id,
  choice: asChoice(i.choice),
  intensity: asTier(i.intensity),
  text: i.text,
}));

const tdOut = join(root, 'apps', 'server', 'src', 'content', 'truth-dare-packs.ts');
writeFileSync(tdOut, `import type { ContentPack } from '@bloop/engine';
import type { TruthDareContent } from '@bloop/game-truth-dare';

/**
 * GENERATED by scripts/build-packs.mjs from content/packs/<gameId>.json —
 * do not edit by hand. Undrawn texts are VALUE SECRETS until their draw (the
 * decks/cursors never enter a view). Tier + deck gating is a RUNTIME config
 * gate at init (allowedIntensities + deck), not a build filter: the fun
 * config never draws lover/spicy rows. Same R2 seam as tracer-pack.
 */
export const TRUTH_OR_DARE_2_PACK: ContentPack<TruthDareContent> = {
  id: '${tod2.gameId}-core',
  version: ${tod2.version ?? 1},
  data: { items: ${JSON.stringify(tod2Items, null, 2)} },
};

export const TRUTH_OR_DRINK_PACK: ContentPack<TruthDareContent> = {
  id: '${totd.gameId}-core',
  version: ${totd.version ?? 1},
  data: { items: ${JSON.stringify(totdItems, null, 2)} },
};
`);
console.log(`truth-dare-packs.ts regenerated — truth-or-dare-2: ${tod2Items.length} items, truth-or-drink: ${totdItems.length} items`);
```

Emitted export names: `TRUTH_OR_DARE_2_PACK`, `TRUTH_OR_DRINK_PACK`.

## 3. `apps/server/test-node/redaction-audit.test.ts` — AUDITS fixtures

Event helpers (next to `vote`/`ballot`/`igGuess`):

```ts
const tdChoose = (playerId: string, choice: 'truth' | 'dare', at: number): GameEvent<unknown> =>
  ({ type: 'action', playerId, action: { kind: 'chooseType', choice }, at });

const tdDeclare = (playerId: string, at: number): GameEvent<unknown> =>
  ({ type: 'action', playerId, action: { kind: 'declare', result: 'done' }, at });

const tdVote = (playerId: string, vote: 'done' | 'chickened', at: number): GameEvent<unknown> =>
  ({ type: 'action', playerId, action: { kind: 'verdict', vote }, at });

/** truth-dare: the next-undrawn text of every deck is a VALUE secret until its draw. */
const tdUndrawnTexts = (state: unknown): ReadonlyArray<{ value: string }> => {
  const s = state as {
    decks: Record<string, string[]>;
    cursors: Record<string, number>;
    itemsById: Record<string, { text?: { fr: string; en: string } }>;
  };
  const out: Array<{ value: string }> = [];
  for (const key of Object.keys(s.decks)) {
    const id = s.decks[key]?.[s.cursors[key] ?? 0];
    const t = id === undefined ? undefined : s.itemsById[id]?.text;
    if (t !== undefined) out.push({ value: t.fr }, { value: t.en });
  }
  return out;
};
```

Fixtures (append inside the `AUDITS` map). The seeded rotation for
`'audit-seed'` + `['p1','p2','p3']` is **[p3, p1, p2]** — the scripted actors
below depend on it; verified by this package's `integration-audit.test.ts`:

```ts
  ['truth-or-dare-2', {
    players: ['p1', 'p2', 'p3'],
    seed: 'audit-seed',
    // rotation under 'audit-seed' is [p3, p1, p2]. Park MID-VERDICT of turn 1
    // (turn 1, not 0, keeps the deadline walk within the 25-step audit
    // budget: 23 steps to 'over') with ONE of two expected votes buffered.
    events: [
      tdChoose('p3', 'truth', 1_000), tdDeclare('p3', 2_000),
      tdVote('p1', 'done', 3_000), tdVote('p2', 'done', 4_000), // turn 0 resolves
      { type: 'deadline', at: 5_000 }, // score:0 -> choose:1 (active p1)
      tdChoose('p1', 'truth', 6_000), tdDeclare('p1', 7_000),
      tdVote('p2', 'done', 8_000),
    ],
    eventsAlt: [
      tdChoose('p3', 'truth', 1_000), tdDeclare('p3', 2_000),
      tdVote('p1', 'done', 3_000), tdVote('p2', 'done', 4_000),
      { type: 'deadline', at: 5_000 },
      tdChoose('p1', 'truth', 6_000), tdDeclare('p1', 7_000),
      tdVote('p2', 'chickened', 8_000), // ONLY p2's hidden vote differs
    ],
    actors: ['p2'],
    secrets: tdUndrawnTexts,
  }],
  ['truth-or-drink', {
    players: ['p1', 'p2', 'p3'],
    seed: 'audit-seed',
    // no choose beat (allowedChoices ['truth']): init lands in prompt:0 with
    // active p3. Park mid-verdict turn 0, ONE of two expected votes buffered;
    // deadline walk to 'over' is 12 steps (6 turns x 2, no choose).
    events: [tdDeclare('p3', 1_000), tdVote('p1', 'done', 2_000)],
    eventsAlt: [tdDeclare('p3', 1_000), tdVote('p1', 'chickened', 2_000)],
    actors: ['p1'],
    secrets: tdUndrawnTexts,
  }],
```

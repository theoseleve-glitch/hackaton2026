# @bloop/game-input-guess — integration

INPUT_GUESS template, two zero-text numeric modes (wave-2 design §2.4/§2.5):

| gameId | Mode | Phases (phaseKey) | Durations |
|---|---|---|---|
| `quizz-culture-ge` (Au Pif ! / Ballpark!) | `closest-number` | `guess:r{n}` → `reveal:r{n}` → `over` | 20s / 12s / untimed |
| `cinquante-cinquante` (Fifty-Fifty) | `crowd-target` | `pick:r{n}` → `reveal:r{n}` → `over` | 25s / 12s / untimed |

Both games: 2–16 players. `answer` / `funFact` / `crowdYesPct` are VALUE
SECRETS until the atomic reveal. Every snippet below is verified by
`test/integration-audit.test.ts` in this package, which replays the §2 adapter
and the §3 fixtures against the real authored packs — keep them in sync.

Dependency note: `apps/server/package.json` and `apps/mobile/package.json`
already declare `"@bloop/game-input-guess": "workspace:*"` — no package.json
edit is needed.

## 2. Server pack consts — `scripts/build-packs.mjs` adapter

Append this block to `scripts/build-packs.mjs`, then run
`node scripts/build-packs.mjs` from the bloop root. It emits
`apps/server/src/content/input-guess-packs.ts` with the export names
**`QUIZZ_CULTURE_GE_PACK`** and **`CINQUANTE_CINQUANTE_PACK`**
(both typed `ContentPack<InputGuessContent>`).

```js
// ---------------------------------------------------------------------------
// input-guess: quizz-culture-ge (closest-number) + cinquante-cinquante
// (crowd-target) -> apps/server/src/content/input-guess-packs.ts
// ---------------------------------------------------------------------------
const qcg = load('quizz-culture-ge');
// Strip authoring-only fields (tags, difficulty, verifiedAt, source); spicy 0 only.
const qcgItems = qcg.items
  .filter((i) => (i.spicy ?? 0) === 0)
  .map((i) => ({
    id: i.id,
    question: i.question,
    answer: i.answer,
    unit: i.unit ?? null,
    format: i.format === 'year' ? 'year' : 'plain',
    scale: i.scale === 'log' ? 'log' : 'linear',
    funFact: i.funFact,
  }));

const cct = load('cinquante-cinquante');
// Core pack = classic tone with EVERY completion spicy 0. Items containing any
// spicy card are dropped whole — filtering single cards would break the
// exactly-cardsPerRound (6) hand the pick-range validator counts on.
const cctItems = cct.items
  .filter((i) => (i.tone ?? 'classic') === 'classic' && i.completions.every((c) => (c.spicy ?? 0) === 0))
  .map((i) => ({
    id: i.id,
    targetYesPct: i.targetYesPct,
    askKind: i.askKind,
    stem: i.stem,
    completions: i.completions.map((c) => ({ id: c.id, text: c.text, crowdYesPct: c.crowdYesPct })),
  }));

const igOut = join(root, 'apps', 'server', 'src', 'content', 'input-guess-packs.ts');
writeFileSync(igOut, `import type { ContentPack } from '@bloop/engine';
import type { InputGuessContent } from '@bloop/game-input-guess';

/**
 * GENERATED by scripts/build-packs.mjs from content/packs/<gameId>.json —
 * do not edit by hand. answer / crowdYesPct / funFact are VALUE SECRETS until
 * reveal (they never enter pre-reveal views). Same R2 seam as tracer-pack.
 */
export const QUIZZ_CULTURE_GE_PACK: ContentPack<InputGuessContent> = {
  id: '${qcg.gameId}-core',
  version: ${qcg.version ?? 1},
  data: { items: ${JSON.stringify(qcgItems, null, 2)} },
};

export const CINQUANTE_CINQUANTE_PACK: ContentPack<InputGuessContent> = {
  id: '${cct.gameId}-core',
  version: ${cct.version ?? 1},
  data: { items: ${JSON.stringify(cctItems, null, 2)} },
};
`);
console.log(`input-guess-packs.ts regenerated — quizz-culture-ge: ${qcgItems.length} items, cinquante-cinquante: ${cctItems.length} items`);
```

## 3. Audit fixtures — `apps/server/test-node/redaction-audit.test.ts`

Add the event helpers next to `vote` / `ballot`:

```ts
const igGuess = (playerId: string, value: number, at: number): GameEvent<unknown> =>
  ({ type: 'action', playerId, action: { kind: 'guess', value }, at });

const igPick = (playerId: string, cardIndex: number, at: number): GameEvent<unknown> =>
  ({ type: 'action', playerId, action: { kind: 'pick', cardIndex }, at });
```

Add the entries to the `AUDITS` map. These exact fixtures (same seed, events
and secrets) are pinned green against the real packs by
`packages/games/input-guess/test/integration-audit.test.ts`:

```ts
  ['quizz-culture-ge', {
    players: ['p1', 'p2', 'p3'],
    seed: 'audit-seed',
    // mid-guess round 0: two secret guesses buffered, p3 still expected — phase NOT advanced.
    // Guess values are chosen so no digit string collides with the round-0 answer
    // (the owner echo would otherwise false-positive the substring audit).
    events: [igGuess('p1', 23, 1_000), igGuess('p2', 47, 2_000)],
    eventsAlt: [igGuess('p1', 56, 1_000), igGuess('p2', 89, 2_000)],
    actors: ['p1', 'p2'],
    // the current item's verified answer + funFact are VALUE secrets until reveal
    secrets: (state) => {
      const s = state as {
        round: number;
        items: Array<{ answer?: number; funFact?: { fr: string; en: string } }>;
      };
      const item = s.items[s.round];
      if (item?.answer === undefined || item.funFact === undefined) return [];
      return [
        { value: String(item.answer) },
        { value: item.funFact.fr },
        { value: item.funFact.en },
      ];
    },
  }],
  ['cinquante-cinquante', {
    players: ['p1', 'p2', 'p3'],
    seed: 'audit-seed',
    // mid-pick round 0: two secret card picks buffered, p3 still expected — phase NOT advanced
    events: [igPick('p1', 0, 1_000), igPick('p2', 1, 2_000)],
    eventsAlt: [igPick('p1', 4, 1_000), igPick('p2', 5, 2_000)],
    actors: ['p1', 'p2'],
    // the current item's pre-computed crowd percentages are VALUE secrets until reveal
    secrets: (state) => {
      const s = state as {
        round: number;
        items: Array<{ completions?: Array<{ crowdYesPct: number }> }>;
      };
      const item = s.items[s.round];
      return (item?.completions ?? []).map((c) => ({ value: String(c.crowdYesPct) }));
    },
  }],
```

Deadline-walk budget: from the fixture state, `quizz-culture-ge` reaches `over`
in 16 deadline steps (8 rounds × guess+reveal) and `cinquante-cinquante` in 14
(7 × 2) — both ≤ 25.
